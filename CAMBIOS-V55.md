# V55 · Control económico

Nuevo apartado **Gastos** en los accesos rápidos del panel privado.

Incluye presupuesto editable, resumen de gastado/restante, aportaciones de David y Raquel, balance al 50 %, pagos pendientes, alta/edición/borrado de gastos, reparto individual/50-50/personalizado, forma de pago, referencia, estado, vencimiento, control de facturas, URL de documentos, observaciones, búsqueda, filtros y exportación CSV.

## Instalación

1. Ejecuta `SUPABASE-V55-CONTROL-ECONOMICO.sql` en el editor SQL de Supabase.
2. Publica todos los archivos de esta carpeta sustituyendo la versión anterior.
3. Entra en `/admin/` y usa el nuevo acceso rápido **Gastos**.

Los documentos se guardan como enlaces URL para evitar exponer el almacenamiento. Puedes usar una URL privada o firmada de Supabase Storage, Google Drive, Dropbox, etc.
